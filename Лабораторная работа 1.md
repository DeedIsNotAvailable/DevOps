# Лабораторная работа 1

## Зачем

Упаковать приложение вместе со средой так, чтобы оно запускалось везде, где есть Docker.

Скрапер выбран не случайно: ему нужен браузер внутри образа - это больше гигабайта, которые вы не захотите качать при каждой правке кода. Также для самого браузера нужно будет накатить большое количество библиотек.

Этот же скрапер поедет во все следующие лабы: в облако, на сервер, в кластер.

---

## Что делаем

1. **Скрапер** на Playwright: открывает `https://quotes.toscrape.com/scroll` в Chromium, достаёт цитаты, пишет в `out/result.json`. Данные подгружаются JS - в исходном HTML их нет.
2. **Multistage `Dockerfile`** - один образ, несколько стадий сборки.
3. **Makefile** - `build`, `run`, `clean`, `ci`. Единственная точка входа.
4. **CI** - GitHub Actions вызывает `make ci`.
5. **Pull request** из `feat/quotes-scrapper` в `main`.

<aside>

Готовый образ `mcr.microsoft.com/playwright` или аналоги брать нельзя - собираете среду сами от `node:22-bookworm`.

</aside>

<aside>

Если команды нет в Makefile - её не существует. Ручных `docker`-команд в терминале быть не должно.

</aside>

## Примерная структура

```
repo/
├─ Dockerfile
├─ Makefile
├─ src/                              # исходный код скрапера
├─ package.json/package-lock.json    # или аналоги, смотря на каком языке пишите
├─ out/                              # результат, в git не коммитится
└─ .github/workflows/ci.yml
```

Код скрапера вы пишете сами

## Definition of Done

<aside>

Все 8 пунктов - 16 баллов. Любой не выполнен - лаба не принята, дорабатываете и приходите снова. Прием работы происходит на любой паре “Лабораторная работа”

</aside>

1. Открыт PR из `feat/quotes-scrapper` в `main`, до защиты не смержен
2. `make build` собирает образ
3. `make run` - в `out/result.json` непустой валидный JSON с цитатами
4. `make clean` удаляет образ и `out/`, `git status` чистый
5. Повторный `make build` после `make clean` не качает браузер заново
6. Правка одной строки кода не пересобирает ни браузер, ни зависимости
7. CI зелёный на последнем коммите PR, вызывает `make`
8. В `README.md`: короткое описание проекта, как настраиваем локальное окружение для разработки и как собираем продакшн образ
